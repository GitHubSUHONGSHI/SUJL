Selected Projects

重点项目经历

围绕 AI 应用、中后台平台和高并发增长链路，呈现架构判断、职责边界和工程结果。

项目 01 某企业级 SaaS 平台｜AI Copilot 工作台｜前端架构与 LLM 接入

面向内部业务人员构建 AI 辅助工作台，覆盖问答检索、任务生成、表单自动填充、工具调用和业务知识引用等场景。

项目背景
业务团队需要把分散在知识库文档、工单记录和系统字段中的知识接入统一工作台，降低人工检索和重复整理成本。
技术挑战
多轮对话状态复杂、上下文长度受限、知识召回结果需要可追溯，同时要处理权限隔离、幻觉提示、敏感字段脱敏、响应稳定性与失败兜底。
个人职责
负责对话工作台前端架构、核心交互开发、Node 接入层联调、SSE 流式渲染方案、引用展示和异常兜底策略。
技术方案
基于 React + TypeScript 设计对话容器、消息模型和引用卡片，通过 Node BFF 统一封装 LLM API、Embedding 检索、RAG 结果、工具调用、权限校验、SSE 事件和埋点监控。
项目结果
完成 AI 助手从 0 到 1 试点上线，沉淀可复用对话组件、流式响应规范和接入检查清单；检索整理耗时从约 20 分钟降至 6 分钟，覆盖 120+ 内部用户。
项目 02 某数据智能平台｜低代码数据运营后台｜Schema 与权限体系

建设面向运营、产品和分析团队的数据配置平台，支持复杂表单、权限审批、看板配置和流程编排。

项目背景
运营配置需求高频变化，历史页面由多个团队重复开发，字段、权限和审批逻辑分散，交付质量不稳定。
技术挑战
业务模型变化频繁，表单和审批链路复杂，跨团队协作成本高，平台稳定性直接影响运营配置效率。
个人职责
主导模块拆分、组件抽象、RBAC 权限模型、Schema 表单引擎优化和关键页面性能治理。
技术方案
使用 Vue + TypeScript 建设 Schema Driven UI，抽象字段组件、校验规则、审批状态和 RBAC 权限，配合接口聚合与前端缓存降低页面复杂度。
项目结果
提升配置化页面复用率，降低重复开发、权限误配和线上变更风险；常规运营页面交付周期从 5 天缩短到 2 天，沉淀 20+ 个通用组件。
项目 03 某增长业务团队｜高并发活动系统｜性能治理与灰度发布

负责核心增长活动、转化链路和多端页面体系建设，覆盖 Web、H5、小程序与内部投放配置链路。

项目背景
增长活动需要快速上线并承接短时间流量峰值，同时要支持不同端的投放页面、实验策略和转化数据回收。
技术挑战
活动流量峰值明显，页面链路长，多端适配复杂，对首屏性能、灰度发布、监控告警和问题回滚要求高。
个人职责
负责核心活动页面架构、首屏性能优化、组件复用、发布流程治理、埋点联调和线上问题排查。
技术方案
基于 Vite/Webpack 优化构建链路，结合预渲染、CDN 缓存、图片资源治理、A/B 实验、埋点体系和灰度回滚保障发布质量。
项目结果
保障重点活动稳定上线，沉淀可复用活动模板、性能检查清单和发布回滚流程；移动端 LCP 从 3.2s 优化到 1.9s，活动峰值期间日均 8-12 万 PV。
